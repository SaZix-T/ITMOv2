## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: провести ревью TRAINING_PR.diff и выявить проблемы только внутри текущей программы.
- Роль AI: Ai-reviewer.

### 2. Входы и источники

- Обязательный вход: TRAINING_PR.diff.
- Разрешённые файлы и источники: TRAINING_PR.diff, context.md, problem.md, prompts.md.
- Context Pack — факты, правила, примеры и ограничения: см. context.md (эндпоинт POST /api/reviews, использование payload["diff"], формирование промпта и вызов LLM.generate, формат ответа, ограничения — нет валидации, нет лимита размера diff).

### 3. Задача и артефакты

- Что сделать: найти риски/проблемы по диффу, оставить только те, для которых есть доказательства в файлах; для каждого описать проверку.
- Что вернуть: краткий ответ с не более чем 2 рисками; для каждого — Кандидат, Доказательство (ссылка на файл/строку), Проверка.

### 4. Формат результата

- Структура ответа: список пунктов вида — Кандидат; Доказательство; Проверка.
- Ограничения объёма: кратко, меньше трёх рисков; без избыточных деталей.

### 5. Полномочия и запреты

- Разрешено: читать указанные файлы; опираться только на предоставленные источники; указывать конкретные строки/файлы.
- Запрещено: approve/merge; выполнять shell-команды; придумывать правила вне context.md; изменять файлы вне перечисленных источников.

### 6. Рабочий процесс и остановка

- Шаги: прочитать TRAINING_PR.diff; соотнести с context.md; составить список кандидатов; отфильтровать без evidence; сформировать проверки; вернуть краткий ответ.
- Когда остановиться и запросить человека: если отсутствует TRAINING_PR.diff или контекст противоречив.

### 7. Проверки и evidence

- Как проверять утверждения: воспроизводимые шаги (вызов эндпоинта с примерами payload), указание точных мест в diff.
- Какое evidence сохранить: ссылки на файлы и строки из TRAINING_PR.diff и/или app/*.py.

### 8. Definition of Done

- Задача закончена, когда: перечислены до 2 рисков с доказательствами и проверками; соблюдены запреты и формат; вывод опирается на TRAINING_PR.diff/context.md.

## Сравнение двух запусков

| Проверка | Zero-shot | С master prompt | Вывод команды |
|---|---|---|---|
| Есть ссылка на файл или строку | Нет | Да | Требуются явные ссылки на файл/строку |
| Вывод подтверждён diff или правилом | Частично | Да | Утверждения подтверждаем из TRAINING_PR.diff и context.md |
| Соблюдены границы AI | Частично | Да | Рассматриваем только риски внутри программы, без внешних требований |
| Есть воспроизводимая проверка | Нет | Да | Для каждого риска — пошаговая проверка |
