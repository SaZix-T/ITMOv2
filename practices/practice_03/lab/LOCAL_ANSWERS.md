1. Как запустить тесты?

Файл-источник: demo/Makefile или demo/test_service.py

Для запуска тестов выполните:
make test

Или прямо:
python3 -m unittest -v demo/test_service.py

При пустом имени подписчика будет выброшено исключение ValueError с сообщением "empty name".

5. Сохраняются ли подписки после перезапуска процесса?

Нет, подписки не сохраняются после перезапуска процесса Python.

Доказательство из кода:

В demo/service.py:

subscribers = set()

Глобальная переменная объявлена как простой объект в памяти. При:
- Перезапуске Python интерпретатора (например, через сигналы SIGHUP)
- Рестарте сервера/процесса
- Выполнении python -c 'from service import subscribers' заново

Модуль пересоздаётся с чистым состоянием. В тестах это явно используется:

В demo/test_service.py:

def setUp(self):
    subscribers.clear()  # Очистка между тестами

Глобальные переменные не имеют механизма сохранения состояния между запусками процесса Python.
