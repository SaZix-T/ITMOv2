# Отчет

Проект представляет собой трекер задач с возможностью добавлять описание и устанавливать дату, в которую задача должна быть выполнена.

В рамках текущего домашнего задания были добавлены две новые функции: возможность выставления приоритета для задач и статистика по количеству выполненных задач.

Для реализации новых функций был применен подход Spec-Driven Development (SDD). Работа велась с помощью фреймворка GitHub Spec Kit, так как он бесплатный, позволяет выполнить инициализацию в уже готовом проекте одной командой в терминале и не требует ручной настройки.

Также фреймворк позволяет настроить интеграцию команд в opencode для дальнейшей работы.

После добавления функций с использованием SDD были запущены тесты и проверена работоспособность сервиса.
