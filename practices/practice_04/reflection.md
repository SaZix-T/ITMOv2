# Отчет

Проект представляет собой трекер задач с возможностью добавлять описание и устанавливать дату, в которую задача должна быть выполнена

Был создан скилл, который указывает, что после каждого изменения кода проекта необходимо запустить скрипт, который запустит тесты, а затем проверить их успешное прохождение
Работаспособность скилла была проверена с помощью запроса к модели

Также для данного проекта был написан mcp сервер, который позволяет получать все задачи, активные задачи, завершенные и просроченные задачи
Работаспособность mcp сервера была проверена с помощью запуска MCP inspector и с помощью запроса к модели
MCP спроектирован как read-only для предотвращения изменения данных

Создан hook, который запускает тесты на заранее обозначенных путях после изменения в кодовой базе проекта, минуя файлы, для которых нет необходимости в тестировании

В первой версии плагина использовался путь `worktree || directory`, из-за чего `npm test` уходил в корень репозитория и падал с `ENOENT …/ITMOv2/package.json`
Это было исправлено

Также был написан файл `AGENTS.md`, в котором описана общая структура проекта и его предназначение
В данном файле указан процесс запуска веб сервиса и правила, которые необходимо применять во время разработки, так же описано definition of done и ограничения для моделей (разрешено, сначала спросить, запрещено), в конце описано, что необходимо сделать в ситуациях таких, как провал при прохождении тестов, или если стандартный порт будет занят
