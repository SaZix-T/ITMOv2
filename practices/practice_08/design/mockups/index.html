TaskFlow — пять вариантов макета

Один и тот же экран и одинаковый набор состояний, разные библиотеки компонентов и характер. Внизу слева у каждого макета — панель «МАКЕТ»: она переключает список, загрузку, пустое состояние, ошибку и диалог.

Если панель не видна, прокрути страницу внутри рамки вниз или открой макет отдельно по ссылке под ним. Все макеты статические: данные и ответы сервера не запрашиваются.

1. Орбита

Shoelace 2.15 · Space Grotesk + Inter

Тёмный космос с тонкими орбитами и холодным циановым светом. Стеклянные карточки, веб-компоненты библиотеки.

Открыть отдельно

2. Туманность

DaisyUI 5 · Manrope

Фиолетово-розовая туманность, мягкое свечение, крупные скругления. Самый «неоновый» из вариантов.

Открыть отдельно

3. Пульт

Bootstrap 5.3 · IBM Plex Sans + Mono

Пульт управления: телеметрия слева, плотные строки задач, янтарный акцент. Строгий инженерный вид.

Открыть отдельно

4. Луна

Pico CSS 2 · Unbounded + Inter

Тихий минимализм лунной базы: ледяной акцент, много воздуха, крупная типографика, почти без декора.

Открыть отдельно

5. Станция

Beer CSS 3.12 (Material 3) · Rubik

Бортовая система: боковая навигация по «секторам», мятный акцент, тональные поверхности Material 3.

Открыть отдельно
