# Макет и дизайн

## Пять вариантов

Все варианты показывают один и тот же экран и один и тот же набор состояний, чтобы
сравнивать дизайн, а не тексты. Общая спецификация — `design/mockups/SPEC.md`,
галерея — `design/mockups/index.html`.

| № | Название | Библиотека | Характер |
|---|---|---|---|
| 1 | Орбита | Shoelace 2.15 (веб-компоненты) | холодный циан, орбитальные кольца, стеклянные карточки |
| 2 | Туманность | DaisyUI 5 | фиолетово-розовая туманность, мягкое свечение, крупные скругления |
| 3 | Пульт | Bootstrap 5.3 | mission control: телеметрия слева, плотные строки, янтарь |
| 4 | Луна | Pico CSS 2 | тихий минимализм, ледяной акцент, много воздуха |
| 5 | Станция | Beer CSS 3.12 (Material 3) | бортовая система, боковые «секторы», мятный акцент |

Выбран вариант **2 «Туманность»** на DaisyUI: он ближе всего к запросу «тёмная тема
с космической направленностью», при этом остаётся рабочим инструментом — карточки
читаются, кнопки очевидны, акценты не мешают.

Файл выбранного макета: `design/mockups/variant-2-tumannost.html`.

## Что есть в макете

Макет — интерактивный HTML-прототип, а не картинка. Внизу слева панель «МАКЕТ»
переключает пять состояний:

- `list` — список из четырёх задач, уведомление «Задача создана»;
- `loading` — три скелетона и подпись «Загружаем задачи…»;
- `empty` — «Задач пока нет» и кнопка создания;
- `error` — «Не удалось загрузить задачи» и кнопка «Повторить»;
- `dialog` — модальное окно создания с валидацией названия.

Панель переключает состояния без обращения к серверу: это прототип. В финальном
интерфейсе те же состояния появляются от реальных запросов.

## Что предложил AI и что исправили

AI сгенерировал пять прототипов по одной спецификации и отдельно — описание сценария.
Проверка скриншотами и живым кликом нашла несколько проблем, которые исправили вручную:

- в «Орбите» чекбокс Shoelace растянулся в блок 300×300 — в выбранный вариант это
  не попало, но в галерее видно, почему макет проверяют, а не принимают на слово;
- в «Станции» карточки остались светлыми: переменные Material 3 не переопределились;
- в «Туманности» счётчики 8/5/3 не сходились с четырьмя показанными задачами —
  заменили на 4/3/1;
- в «Туманности» выделенный пункт панели «МАКЕТ» и фокус были циановыми; по просьбе
  заказчика сделали фиолетовыми, чтобы не выбивались из темы;
- поправили опечатку в названии доклада (Typst) и аббревиатуру БГД.

## Соответствие макета и реализации

| Макет | Реализация |
|---|---|
| шапка с поиском и кнопкой «Новая задача» | `public/index.html`, блок `.app-header` |
| сводка 4 / 3 / 1 | `.summary`, значения считаются из `state.tasks` |
| фильтры «Все / Активные / Выполненные» | `.filters`, фильтрация на клиенте |
| карточка задачи | `taskCard()` в `public/js/app.js` |
| уведомление «Задача создана» | `#toast`, `showToast()` |
| скелетоны загрузки | `#state-loading` |
| «Задач пока нет» | `#state-empty`, текст зависит от поиска и фильтра |
| «Не удалось загрузить задачи» | `#state-error` + кнопка «Повторить» |
| диалог «Новая задача» | `<dialog id="task-dialog">` |

Отличия от макета, которые появились при реализации:

- в карточках заработали «Изменить» и «Удалить»: редактирование открывает тот же диалог
  с заполненными полями, удаление — отдельный диалог подтверждения;
- добавилось состояние «Ничего не нашлось» для поиска и «Здесь пока пусто» для фильтра;
- просроченный срок подсвечивается красным, сегодняшний — янтарным;
- после создания задачи фильтр сбрасывается на «Все», чтобы новая карточка не потерялась;
- фокус и активные элементы — фиолетовые, без циановых акцентов;
- макетная панель «МАКЕТ» в приложение не переносится: это инструмент ревьювера.

## Токены темы

Всё задано в `public/styles/app.css`:

- палитра — `:root` (`--bg`, `--surface`, `--primary`, `--accent`, `--danger`…)
  и переопределение переменных DaisyUI в `html[data-theme="synthwave"]`;
- типографика — Manrope для текста, JetBrains Mono для метаданных и цифр;
- отступы — `.shell`, `.app-header`, `.summary`, `.task-card`, `.field` (шаг 4–24 px);
- радиусы — `--radius-box: 20px`, `--radius-field: 12px`, кнопки 11 px;
- фокус — единое правило `:focus-visible` с обводкой 2 px цветом `--accent`.

Компоненты DaisyUI, которые используются: `.btn` (primary, ghost, error), `.input`,
`.textarea`, `.card`, `.badge`, `.alert`, `.modal` + `<dialog>`, `.loading`,
`.checkbox`. Кастомный CSS отвечает за палитру, фон-туманность, сетку и состояния,
а не заменяет компоненты.
