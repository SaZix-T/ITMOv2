# Нагрузочные проверки

Ниже сценарии и пороги для сервиса AI-помощника ревьюера PR. Они опираются на правила из CASE.md (SEC-1, API-1, REL-1, OUT-1, QA-1, OBS-1) и проверяются на локальном стенде.

## Сценарии и пороги

|---|---|---|---|---|

## Методика и окружение

- Стенд: локально, сервис на http://localhost:8080. Если рабочего сервиса нет, используйте минимальный стенд с заглушкой внешнего LLM.
- Данные: `practices/practice_01/TRAINING_PR.diff` как базовый diff; генератор добавляет паддинг для целевой длины.
- Инструменты: k6 v0.49+, curl 7.88+, Python 3.11+ (для заглушек), jq (для валидации логов).
- Конфигурация LLM-заглушки: переменные окружения `LLM_DELAY_MS=300` для стабильной задержки и `LLM_DELAY_MS=12000` для сценария таймаута.
- Повторы: каждый сценарий — 3 прогона; берём медиану по p95.
- Отчётность: сохраняем raw-логи k6 и сервисные логи в артефакты прогона.

Пример k6 (сокращённый):

```js
// save as k6_review.js
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = { vus: __ENV.VUS || 10, duration: __ENV.DUR || '1m' };

function genDiff(target) {
  const base = 'diff --git a/a b/b\n';
  const pad = 'x'.repeat(Math.max(0, target - base.length));
  return base + pad;
}

export default function () {
  const len = Number(__ENV.LEN || 10000);
  const res = http.post('http://localhost:8080/review', genDiff(len), {
    headers: { 'Content-Type': 'text/plain' },
  });
  check(res, { 'status ok or 413': r => [200, 201, 202, 413].includes(r.status) });
  sleep(0.1);
}
```

Запуск примеров:

```bash
# Сценарий 1: порог по длине
LEN=19000 k6 run k6_review.js
LEN=21000 k6 run k6_review.js

# Сценарий 2: 50 VU, 5 минут
VUS=50 DUR=5m LEN=8000 k6 run k6_review.js

# Сценарий 3: таймаут внешнего LLM
export LLM_DELAY_MS=12000
VUS=10 DUR=2m LEN=8000 k6 run k6_review.js
```

Минимальная заглушка внешнего LLM (Python):

```python
# llm_stub.py
from http.server import BaseHTTPRequestHandler, HTTPServer
import os, time

class H(BaseHTTPRequestHandler):
    def do_POST(self):
        delay = int(os.getenv('LLM_DELAY_MS', '300')) / 1000.0
        time.sleep(delay)
        self.send_response(200)
        self.end_headers()
        self.wfile.write(b'{"ok": true}')

HTTPServer(('0.0.0.0', 9090), H).serve_forever()
```
